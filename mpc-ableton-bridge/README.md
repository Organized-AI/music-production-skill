# mpc-ableton-bridge

A plan for getting an Akai MPC One+ (standalone) and Ableton Live on Windows to work together: shared clock, MIDI in both directions, audio back into Live, and an optional AbletonMCP layer so Claude can drive Live.

## Recommended setup

The MPC stays standalone and Ableton is the clock master and recorder. One pair of 5-pin MIDI cables carries clock and notes, and the MPC's stereo outs go into the audio interface.
